| Rubric item | Before | Now |
|---|---|---|
| `min_app_version` at or above the SDK floor | `0.1.0`, and CLI 0.1.13 stamped it unchanged (not submittable) | `2.2.10`; CLI 0.2.0 also stamps the floor |
| Name is the same in app.json, on the glasses and on the phone | `epub-reader` / `G2 ePUB Reader` / `ePub Reader` | `ePub Reader` everywhere (enforced by `tests/app-json.test.ts`) |

| Root double-tap exit uses `shutDownPageContainer(1)` | already compliant (`even-client.ts`, `exit` route) | unchanged |

## 2. Release steps

These need the developer's accounts.

1. **Deploy the relay** (`relay/README.md`): run `npx wrangler deploy` and note
   the origin.
2. **Point the app at it**:
   - In `app.json`, set the network whitelist to `["<relay origin>"]`.
   - In `PRIVACY.md`, replace `RELAY_ORIGIN` with the origin and publish the
     policy at a public URL. The repository URL of the file is fine.
3. **Build the package**: `VITE_RELAY_ORIGIN=<relay origin> npm run pack`
   produces `epub-reader.ehpk`. The release check refuses a build whose relay
   and whitelist don't match.
4. **Log in**: run `npx evenhub login` (interactive).
5. **Upload**:
   - Run `npx evenhub upload epub-reader.ehpk -m "<English release note>"`. The
     changelog is required and limited to 500 characters.
   - Use `npx evenhub ls me.proton.evendev.epubreader` to confirm the version
     is higher than any existing build. Builds are fix-forward only.
6. **Run the pre-submit loop on hardware**:
   - Beta install, then lock the phone for 5 minutes and check that reading
     resumes.
   - Background the Even App with a 2 minute idle and check the same.
   - Check that double-tap on the root (main menu) exits and that the phone
     WebView closes.
   - Relaunch the app.
   - Turn on KOSync and do a round trip with KOReader: push from the glasses,
     open in KOReader, read on, then use "Sync progress" on the glasses.
7. **Complete the listing in the portal** (see §3) and submit.

## 3. Listing content

**Name:** ePub Reader (11 chars; limit 20, no "Even")

**Tagline:** Read EPUB books on your Even G2 glasses (40 chars; limit 50)

**Description:** the `description` field in `app.json` (well under 2000 chars).

**Icon:** `store/icon.png`, 24×24, `#F4F4F4` on transparent, 2×2 blocks.
- It passes the CLI 0.2.0 colour and block rules.
- Add it with `npx evenhub update --icon store/icon.png` or in the portal.
- The portal also asks for a background asset; use the same mark on a plain
  dark background, greyscale only.

**Permission text (network):** the `desc` in `app.json`: "Downloads Project
Gutenberg books and syncs reading progress with your KOReader sync server,
both through the developer's relay."

**Privacy policy:** `PRIVACY.md`, with the relay origin filled in.

**Screenshots:** `store/screenshots/1-main-menu.png` … `5-flow.png`, all 576×288.
- They were captured from the official simulator 0.9.5 through its automation
  API (`/api/screenshot/glasses`), running the real SDK 0.0.16 bridge, so they
  match what the device renders.
- The set: main menu, contents with TOC chapter titles, Paged page with the
  footer, the native hold menu, and Flow running with the WPM footer.

To redo them:
1. Run `npm run dev:serve`.
2. Run `evenhub-simulator "http://localhost:5173/?demo=alices_adventures" --automation-port 9898`.
3. `POST /api/input` the gestures and `GET /api/screenshot/glasses` the frames.

To include "Sync progress" in the menu shot, log in under Progress sync first.

## 4. Known limits (say so in review notes if asked)

- **KOSync precision is one paragraph.**
  - KOReader's percentage is page-based; the glasses' percentage is
    character-based. Positions match by XPointer, so the two percentages can
    differ by a few points for the same place.
  - XPointers that point into images or SVG-only spine items fall back to the
    next text chapter or to the percentage.
- **Some servers answer 404 for a book they have never seen.** Calibre-Web
  and others do this; the app treats it as "no progress yet".
- **The relay requires `https://` sync servers with a public DNS name.** A sync
  server on a home LAN needs a public https hostname, such as a reverse proxy
  or Tailscale Funnel.
- **The companion UI is English only.** `supported_languages` lists the
  languages the reader hyphenates (en/de/es/fr), and
  `tests/app-json.test.ts` enforces that list.
