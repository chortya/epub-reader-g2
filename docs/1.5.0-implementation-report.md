## 2. What landed, by phase

### Phase 1 — data safety (on SDK 0.0.10)
- `f9ce209` v1.4.6 baseline committed (content-ID library, search, tap-hides-info, view-state split).
- `ba5bb18` Position keys migrate when a legacy-ID row is re-keyed to a content ID (`migrateLegacyPositionKeys`).
- `5b88ad6` Content-ID books no longer write the stale title-lane position key.
- `9572f6d` `createPositionPersister`: trailing-800 ms debounce, immediate lifecycle-exit saves,
  flush-before-book-switch with ref-snapshot isolation; `setLocalStorage === false` is now an error;
  L3 last-book keys written once per book open (was up to 5 sequential bridge writes per page turn);
  gesture dispatch serialized (FIFO; lifecycle exits preempt); `refreshCurrentView` exhaustive per view.
- `b06c9d3` Bridge library split: `epub-book-index` + `epub-book-data-<bookId>` authoritative,
  legacy single-blob key dual-written for 1.4.6 rollback; explicit storage-full errors.

### Phase 2 — reading feel
- `072d2fa` **Position format v2**: `{v:2, chapterIndex, pageIndex, wordIndex, offset, paginationVersion}`
  — char offsets into the cleaned chapter text survive repagination exactly. Superset of v1, so a
  rollback to 1.4.6 reads the hints and loses nothing (no mirror keys needed). Paginator tracks
  per-page source offsets (`paginateTextWithOffsets`); flow word ↔ char mapping
  (`flowOffsetForWord` / `flowWordForOffset`); `applySettings` and the info-toggle remap by offset
  (exact) instead of the page-count ratio.
- `1c365c1` **Flicker-free page turns**: unified `readingRenderSig` across paged/flow — matching
  topology renders via `textContainerUpgrade`; menu/welcome rebuilds invalidate it so a stale
  upgrade can never hit menu rows. LRU-2 layout cache: toggling reading info swaps page arrays and
  remaps by offset — no whole-book repagination per toggle.
- `3e1c2b5` **Pixel-accurate text metrics**: `src/text-metrics.ts` wraps `@evenrealities/pretext`
  (firmware-exact LVGL metrics). `formatStatusLine` gained a `maxPx` path — a measured 59-char line
  is 593 px > 576 px, the root cause of the v1.4.1 footer-wrap class. Selection-box widths use the
  real metrics (`computeBoxWidthPx` with injected measure).
- Toolkit **1.7.7** installed (pinned) with a regenerated `patches/even-toolkit+1.7.7.patch`
  (upstream `gestures.ts` unchanged → same hand-applied changes: 40 ms suppression + `resetGestureState`).
  Note: installs need `--legacy-peer-deps` (evenhub-cli peer typescript@^5 vs project TS6, pre-existing).

### Phase 3 — platform (SDK 0.0.15)
- `52612b1` SDK pinned to **0.0.15**; `app.json min_sdk_version` synced (test-enforced).
- `0e2ecc8` **Lifecycle reducer** (`src/lifecycle.ts`): active / overlayOpen / backgrounded —
  native-menu ENTER/EXIT no longer misfires the background path; menu clicks are held until the
  overlay's EXIT delivers them (both event orders tolerated); SYSTEM_EXIT bypasses.
  **Native contextual menu** on reading rebuilds (`menuObject`): Paged = Contents / Switch to Flow /
  Set bookmark / Go to bookmark / Main menu; Flow adds Faster / Slower / Switch to Paged. Static
  verb labels ≤32 UTF-8 bytes, unique non-zero ids, stale clicks view-guarded.
  **textColor hierarchy**: body text per new `Text brightness` setting (1–4, default 4; 0 excluded
  as invisible-dim), footer dimmed to 3 (clock ticker included). **Interruption recovery**:
  Flow swipe = one sentence back/forward while running (chapter jumps moved to menu/Contents);
  auto-rewind to the sentence start (or ~8 words) on resume; quick bookmark stored as a position-v2
  offset. **Chapter time-left** in the Flow footer from measured session pace only (≥60 s and ≥50
  words; never fabricated).
